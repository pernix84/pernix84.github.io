# pernix84.github.io

Source of **<https://pernix84.github.io>**: the MRZ project, a self-hosted, cloud-native platform
that covers the whole delivery chain (plan, build, run, secure, observe), with TM, a
transit-management product, running on it as the proof.

| Path | What |
| --- | --- |
| `docs/` | The site: plain HTML and CSS, no build step. GitHub Pages publishes it from `main` / `docs`. |
| `archive/` | Earlier versions of the page, kept for reference. Not served. |
| `media/components.excalidraw` | Source of the old component diagram, kept for a redraw. |

Preview locally by opening `docs/index.html` in a browser.

Built by Zoltan Kadar.
